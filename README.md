# Linux Practice

This repository contains my Linux command practice while learning DevOps engineering.
My goal in this project is to build strong Linux foundation skills used in system administration and DevOps environments.

## Topics Covered

### 1. File System Navigation

Commands used to move around directories and inspect files.

Commands practiced:

* pwd – show the current working directory
* ls – list files and directories
* cd – change directory
* tree – display folder structure

Example:
pwd
ls
cd filesystem-practice

---

### 2. File and Directory Management

Commands used to create, move, copy, and delete files or directories.

Commands practiced:

* mkdir – create directories
* touch – create empty files
* cp – copy files
* mv – move or rename files
* rm – remove files

Example:
mkdir project-data
touch notes.txt
cp notes.txt backup.txt
mv notes.txt docs/

---

### 3. File Permissions

Commands used to control who can read, write, or execute files.

Commands practiced:

* ls -l – view file permissions
* chmod – change file permissions
* chown – change file ownership

Example:
touch secret.txt
chmod 600 secret.txt
ls -l

---

### 4. Process Monitoring

Commands used to check running programs and system processes.

Commands practiced:

* ps – display running processes
* top – real-time system process monitoring
* kill – terminate a process

Example:
ps aux
top

---

### 5. Disk Usage Monitoring

Commands used to check disk space and storage usage.

Commands practiced:

* df -h – display disk space usage
* du -sh – check directory size

Example:
df -h
du -sh *

---
